## About

I'm a Senior Software Engineer at Okta, working on the Auth0 developer tools. I work on the SDKs, the Auth0 CLI and the Terraform provider, which are the pieces developers touch first when they integrate Auth0, and I care a lot about APIs that feel obvious to use.

Lately I've also been building AI tooling, such as agent skills and evals that check how well AI agents handle real Auth0 integration tasks.

When I'm not coding, you'll probably find me playing MMORPGs like Albion Online.

## What I work on

| Project | What it is |
| --- | --- |
| [**auth0/auth0-cli**](https://github.com/auth0/auth0-cli) | Build, manage and test your Auth0 integrations from the command line |
| [**auth0/go-auth0**](https://github.com/auth0/go-auth0) | Go SDK for the Auth0 Management API |
| [**auth0/terraform-provider-auth0**](https://github.com/auth0/terraform-provider-auth0) | The official Terraform provider for managing Auth0 tenant configuration |
| [**auth0/go-jwt-middleware**](https://github.com/auth0/go-jwt-middleware) | Go middleware for validating JWTs on HTTP requests |
| [**auth0/node-auth0**](https://github.com/auth0/node-auth0) | Node.js SDK for the Auth0 platform |
| [**auth0/auth0-evals**](https://github.com/auth0/auth0-evals) · [**agent-skills**](https://github.com/auth0/agent-skills) | Benchmarks and skills for AI agents working with Auth0 |

**Side project:** [**OpenMorph**](https://github.com/developerkunal/OpenMorph) is a CLI and TUI for safely transforming OpenAPI vendor extension keys, with colorized diffs, dry runs and config merging.
